# Juan Pablo Galvis — Portafolio

Portafolio profesional que presenta mis proyectos de software y perfil como desarrollador Full Stack.

## Proyectos destacados

- **Drovik** — Plataforma de inteligencia logística con arquitectura de microservicios (Angular, .NET, SQL Server, RabbitMQ, YARP, SignalR, Docker)
- **LicoMart** — E-commerce Full Stack con gestión de productos y carrito de compras (React, Tailwind CSS, Django, MySQL, Docker)
- **Dra. Paula Galvis** — Landing page profesional bilingüe para odontóloga, desplegada en producción (React, Tailwind CSS, i18next, Formspree, Netlify)
- **OdontoFlow** — Plataforma de gestión para consultorios odontológicos (en desarrollo)

## Stack

- [Astro](https://astro.build) — Generador de sitios estáticos
- [Motion](https://motion.dev) — Animaciones de scroll
- [Lucide](https://lucide.dev) — Iconos
- [Inter](https://rsms.me/inter/) — Tipografía

## Desarrollo local

```bash
npm install
npm run dev
```

El servidor corre en `localhost:4321`.

## Build

```bash
npm run build
```

Genera el sitio estático en `./dist/`.
